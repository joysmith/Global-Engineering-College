## 3. Hyperlink, Lists, Tables

```html
<!DOCTYPE html>
<html>
<body>
    <h2>Useful Links</h2>
    <a href="https://www.google.com" target="_blank">Visit Google</a><br>
    <a href="mailto:test@example.com">Email Us</a>

    <h2>My Favorite Subjects</h2>
    <ol>
        <li>Data Structures</li>
        <li>Web Technology
            <ul>
                <li>HTML</li>
                <li>CSS</li>
                <li>JavaScript</li>
            </ul>
        </li>
        <li>Databases</li>
    </ol>

    <h2>Class Timetable</h2>
    <table border="1">
        <tr>
            <th>Day</th>
            <th>Subject</th>
        </tr>
        <tr>
            <td>Monday</td>
            <td colspan="1">OOP</td>
        </tr>
        <tr>
            <td rowspan="2">Tuesday</td>
            <td>IWT</td>
        </tr>
        <tr>
            <td>DBMS</td>
        </tr>
    </table>
</body>
</html>
```
